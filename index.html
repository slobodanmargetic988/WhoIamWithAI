The easiest way to begin

Let your agent
set it up.

Open a coding agent on the computer where you use Codex or Claude. Give it this prompt and let it handle the local setup.

  1. Copy the prompt. Use an agent that can work with local files and run commands.
  2. Let it collect your history. It should explain which folders it found and report anything missing.
  3. Review your two playbooks. Keep the clean version for everyday use; open the evidence version when you want to check a rule.

Windows, macOS and Linux launchers are included. Python 3.11+ is required. No paid account with this project is needed.

Prefer to set it up yourself?

Open the public repository ↗ and clone it, or download the ZIP and extract it. Install Python 3.11 or later if it is missing. The app has no additional Python packages.

Windows

cd path\to\WhoIamWithAI
py -3 start.py --collect --open

Or double-click Start.bat and choose to collect your messages and open the app. The launcher also checks for python. Python must be installed first.

macOS / Linux

cd path/to/WhoIamWithAI
python3 start.py --collect --open

On macOS use Start.command; on Linux run sh Start.sh. The menu lets you collect again or open the existing archive.

Open http://127.0.0.1:8765 after the local app starts. Then give your agent the drafting instructions above. Keep the terminal open while browsing; press Ctrl+C there to stop the server. Imports can take time when your history is large.

Scope: collection works with supported local history files, not every cloud chat service. Native Windows execution has not been verified on this project’s current development machine. For Claude Desktop on Windows or histories inside WSL, ask your agent to check source locations and format support rather than assuming everything was found.

Your history doesn’t
come to this website.

This is a static instruction page. It has no account system, upload form, collector service or connection to your local archive.

  • The app runs on your computer.Collection and browsing need no remote service or AI API key. Your archive and generated playbooks are stored locally and excluded from Git.
  • You choose your AI assistant.A cloud-backed agent may process content through its provider when it reads your files. A local archive doesn’t automatically make that analysis offline.
  • The code is public. Your history is yours.Inspect or share the source repository. Keep your own database, transcripts, exports and playbooks off public repositories and web hosting.

A few useful things to know.

Will this generate my playbook as soon as I install it?

No. The app collects and previews your local history. Your own AI agent performs the analysis using the prompt above. It writes editable drafts and validates their evidence; you decide what to keep.

What if I don’t have enough repeated requirements yet?

Your agent should say so. It can separate a few supported preferences from ideas that need more evidence, or explain that the archive is too small to produce a useful playbook. A confident-looking list is not a substitute for your actual choices.

Can I collect new messages later?

Yes. Choose collection again in the launcher. Imports reuse the archive and skip unchanged source files. Ask your agent to revise both playbooks together when you want to include new conversations or changed preferences.

Do I upload this whole project to my web host?

No. This public guide needs only this index.html. The collector, database, local preview and playbooks stay on each user’s computer. Social preview artwork is served from the public source repository; no extra hosted app or server is needed.
